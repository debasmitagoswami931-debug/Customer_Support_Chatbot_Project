# Customer Support Chatbot Using Python

## Project Description
A Machine Learning based customer support chatbot
that identifies customer questions and provides
appropriate responses.

## Features
- Greeting and goodbye responses
- Order status assistance
- Shipping information
- Return and refund information
- Payment information
- Product information
- Business hours
- Human support guidance
- Interactive Streamlit interface

## Technologies
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Logistic Regression
- Streamlit
- Matplotlib

## How to Run

1. Install dependencies:

   pip install -r requirements.txt

2. Run the application:

   streamlit run app.py

## Project Files
- app.py
- chatbot_model.pkl
- chatbot_responses.pkl
- chatbot_dataset.csv
- intent_distribution.png
- confusion_matrix.png
- requirements.txt

## Note
This is an educational intent-classification chatbot.
It responds to questions based on its trained examples.
It does not connect to real orders or payment systems.
